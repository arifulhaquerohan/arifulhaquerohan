# Sakura at dusk

Japanese woodblock-inspired vector landscape: indigo dusk, Mount Fuji, vermilion sun, cherry blossoms, and layered water. The illustration occupies the right side, leaving the name and introduction readable on the left. Palette: #18243e, #637b99, #d95e50, #f4cbd1, #f3eee6. Georgia display type pairs with Arial utility text.

A finite CSS entrance uses transform and opacity: 1800 ms sun reveal with cubic-bezier(.23,1,.32,1), and petal drift over 4400 ms with cubic-bezier(.77,0,.175,1). This is first-visit decorative delight, not an activity indicator. Reduced motion shows a static illustration. No JavaScript, external fonts, raster dependencies, or recurring animation. The diagram and footer stay still.

SVG title and description provide accessible equivalents; the README repeats essential identity and technology details as ordinary text. Previous theme files remain available but are not referenced by the profile.
