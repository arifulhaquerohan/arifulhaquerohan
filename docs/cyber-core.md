# Cybernetic Core

A dark technical illustration for the developer profile. Palette: navy #07111d, cyan #63e3ee, amber #ffbd66, white #eef6fb, slate #a6bece. Arial/Helvetica typography keeps the artwork self-contained. Text stays on the left; a reactor and connecting paths occupy the right.

The user's request for a more animated cyber concept is expressed through slow counter-rotating rings (24 and 16 seconds, linear), three staggered signal packets (4.2 seconds, linear), and a gentle core opacity cycle (4.2 seconds, cubic-bezier(.77,0,.175,1)). Motion is decorative, not a live status indicator. All movement uses transform and opacity; no JavaScript, flashing, external assets, or font requests. Reduced-motion settings stop the animation and hide the packets. The diagram and footer remain static.

The README carries identity and technology details in ordinary text. SVGs also include accessible titles. Previous theme assets remain available but are not used by the README.
