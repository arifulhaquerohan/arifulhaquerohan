# Riverworks

A profile identity inspired by river tributaries and the connections between data, systems, and people.

Palette: river blue #1238a5, current blue #1748bc, mint #b9f5d8, teal #71d6d4, white #f5f9ff, pale water #edf6f4. Arial/Helvetica keeps SVG text self-contained without external font requests. The left-aligned name anchors the header while an abstract river occupies the right third.

The header uses a single finite entrance sequence for first-visit delight: transform and opacity, 1800 ms with a 120 ms stagger, cubic-bezier(.23,1,.32,1). A 2400 ms ripple completes the composition. Text remains static. Reduced-motion preference disables decorative movement. The static SVG remains complete in renderers without CSS animation support.

No scripts, external fonts, remote image services, or additional workflows are needed. The diagram and footer are static to keep reading calm. Previous theme assets are retained but no longer referenced by the README.
